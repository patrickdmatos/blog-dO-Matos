Este é o primeiro post. Todo o conteúdo do blog vive em arquivos **Markdown**
dentro da pasta `content/`, versionados junto com o código.

## Como escrever um post

Crie um arquivo em `content/posts/` com o nome no formato
`AAAA-MM-DD-slug-do-post.md` e um cabeçalho (front matter) em YAML:

```yaml
---
title: Título do post
description: Resumo usado na listagem, no feed e nas redes sociais.
date: 2026-11-18        # opcional se estiver no nome do arquivo
updated: 2026-11-20     # opcional
tags: [laravel, php]
draft: true             # rascunhos não são publicados
cover: /images/capa.jpg # opcional
cover_alt: Descrição da imagem de capa
---
```

## O que o Markdown suporta

- Tabelas, listas de tarefas, ~~riscado~~ e links automáticos (GFM)
- Notas de rodapé[^1]
- Âncoras automáticas nos títulos e sumário
- Realce de sintaxe feito no servidor
- HTML embutido quando precisar de algo a mais

| Recurso          | Suportado |
| ---------------- | :-------: |
| Tabelas          |    Sim    |
| Notas de rodapé  |    Sim    |
| Realce de código |    Sim    |

### Código

```php
Route::get('/posts/{slug}', function (string $slug) {
    return view('blog.show', ['post' => Post::find($slug)]);
});
```

## Publicando

O comando `php artisan blog:build` gera HTML estático em `dist/`, pronto para
o Cloudflare Pages.

<details>
<summary>Por que estático?</summary>

O Cloudflare Pages entrega arquivos pela rede de borda. Sem PHP rodando em
produção, o blog fica mais rápido, barato e seguro.

</details>
